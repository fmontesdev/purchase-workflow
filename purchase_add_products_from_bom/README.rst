This module allows adding products from a Bill of Materials to a
purchase order.

Installation
============

This module depends on:

- purchase_mrp

Usage
=====

To use this module, you need to:

- Open a purchase order and click ``Add Products from BoM``.
- Select the product, the Bill of Materials, and the quantity, then
  click ``Get Products from BoM``.
- Review the generated component lines and adjust quantity or unit price
  if needed.
- If the purchase UoM differs from the product UoM, the quantity is
  converted automatically.
- If a component has its own BoM, you can explode it from the wizard
  using ``Add Products from BoM``.
- If an exploded component needs to be reverted, use
  ``Return Products from BoM``.
- Select the lines to add and click ``Add Products`` to create or update
  the purchase order lines.
